## Ловушки
- **Файлы пишутся только инструментом записи.** Heredoc нельзя — ни для файлов, ни для `python`, ни для `node`: скрипт — файлом в `%LOCALAPPDATA%\dekanat-runs\`. Windows-путь с обратной косой чертой в строке Python ломается: `\r` становится возвратом каретки.
- **Команду с `cd` бери в скобки.**
- **Машина нестабильна.** `npm`, `npx`, `node` — только из Git Bash так: `(cd app && cmd //c "start /b /wait /affinity FFFF0000 npm test")`. `cmd start` не передаёт код возврата: итог — по строкам `passed` и `failed`. Падение с кодом `3221225477` или `3221225622`, `ECONNRESET`, «Page crashed», `ERR_NETWORK_IO_SUSPENDED` без проваленных проверок — повтори один раз и назови оба результата.
- **Время — с часов:** `TZ='<+03>-3' date` — ошибки ИИ 101 и 129. С 23:50 до 00:05 МСК сквозные тесты не запускай.
- **Селектор по подстроке даёт ложный успех** — ошибка ИИ 125: проверяй точным шаблоном.
- **Сквозные тесты зависят от порядка файлов:** доказательство — один файл сразу после `npm run db:seed`.
- **Локальная база** — `127.0.0.1:5432`; перед прогоном `%LOCALAPPDATA%\dekanat-pg\pgsql\bin\pg_isready -h 127.0.0.1 -p 5432`. Не отвечает — не чини, верни в ответе. Красные все тесты подряд — проверь право скриптом `%LOCALAPPDATA%\dekanat-runs\3.7-check-privilege.mjs` с переменной `REPO_DIR`; возвращает право `npm run db:migrate`. Перед отчётом верни набор: `npm run db:seed`. `.env` не читай: скрипт к базе — через `app/scripts/with-env.mjs`.
- `npm run test:e2e` сам заполняет базу и собирает продукт; два прогона одновременно не запускай.
- Каталог `dekanat-runs` целиком не перечисляй: там сотни файлов.
- В `git status` могут быть правки в `docs/briefs/`, `docs/evidence/`, `docs/DECISIONS.md` — записи оркестратора, не предмет ревью.
- **Перед отчётом проверь, что твоих процессов не осталось:** `node`, `next`, `playwright`, `chromium` с папкой проекта в командной строке. Останови только свои; базу и чужие `node` и `chrome` не трогай.
