# Задание: пакет 0.5 — холодный старт

## Роль, модель, effort
Субагент общего назначения (`general-purpose`) — Sonnet 5.5 / high. Только чтение.

## Участник и ветка
А; ветка `docs/0-close`. Субагент работает не в ней, а в чистом клоне ветки `feat/2.4-e2e` во временной папке вне репозитория: это последний отправленный снимок передачи смены 7.

## Цель
Проверить критерий пакета 0.5: «Свежая сессия по одному репозиторию отвечает "что делать дальше"». Субагент не видел ни одного чата проекта и получает только папку. Если он отвечает неверно или чего-то не находит, это дыра в документах, а не его ошибка.

## Входные данные
- Пакет в `tracker.yaml`: 0.5, срок 11.11.
- Требования из матрицы: нет — пакет про процесс.
- Связанные развилки и ADR: нет. Ресерч: нет. Ответы внешних нейросетей: нет.
- Образец для подражания: нет.
- Эталон для сравнения — `docs/HANDOFF.md` в том же клоне. Субагенту он не называется.

## Что сделать
Текст задания субагенту — целиком, без подсказок о содержимом. Вместо `<клон>` при запуске стоит полный путь временной папки:

```
Ты новая сессия проекта в папке <клон>. Ничего не меняй и не запускай git pull. Прочитай CLAUDE.md и выполни раздел "В начале каждой сессии", кроме шагов с вопросами человеку и get_usage. Ответь: что делается в эту смену, какие развилки ждут ответа, какие три файла ты прочёл бы следующими и чего не хватило.
```

Текст задал участник А в промпте [H-014](../../prompts/handoff/H-014.md), пункт 4.

Оркестратор сравнивает ответ с `docs/HANDOFF.md`: что делается в смену, открытые вопросы и развилки, просроченное. Расхождение чинится в документах; затем холодный старт повторяется новым субагентом. Кругов не больше трёх.

## Файлы
- Можно менять: ничего.
- Нельзя трогать: всё.

## Ловушки
- Это имитация: субагент стартует из основной папки сессии и получает её `CLAUDE.md` в контекст сам. Настоящая новая сессия в папке клона — это другой опыт; его может проверить только человек.
- В `CLAUDE.md` сказано, что субагент раздел «В начале каждой сессии» не выполняет. Здесь задание просит обратного; по тому же `CLAUDE.md` для субагента верно задание.

## Готово, когда
- [ ] ответ субагента сходится с `docs/HANDOFF.md` по трём вопросам: что делается в смену, какие развилки и вопросы ждут ответа, что просрочено
- [ ] найденные дыры в документах исправлены или записаны
- [ ] результат каждого круга записан в журнал как есть
- тесты, снимки и строки матрицы: нет

## Ограничения
- Субагент не коммитит и ничего не публикует.
- Только чтение. Файл `.env` не читать.
- Лимит времени на одну команду: две минуты.
