### Пять статусов и три вида заявки — из кода
Статусы, `REQUEST_STATUSES` и `STATUS_LABELS`: `submitted` «Подана», `in_progress` «В работе», `ready` «Готова», `issued` «Выдана», `rejected` «Отклонена». Переходы: Подана → В работе → Готова → Выдана; в «Отклонена» — из «Подана» и «В работе».

Виды, `REQUEST_KIND_INFO`: `dean_certificate` «Справка из деканата», кабинет «120а, 1 корпус»; `tuition_certificate` «Справка об оплате обучения», «118, 1 корпус»; `financial_aid` «Заявление на материальную помощь», «124, 1 корпус».

### Что продукт знает и когда
Оркестратор прочитал `requests.ts` и `page.tsx`; строки про `staff.ts` — со слов ревьюера. Сверь сам и назови в отчёте файл и строку.

| Поле на экране | Источник | Когда известно |
|---|---|---|
| Заголовок | `REQUEST_KIND_INFO[kind].title` | всегда |
| Подпись под заголовком | «Подана <дата>»: `request.createdAt` через `formatDate` | всегда |
| Номер заявки | нет: у заявки только `uuid`, страница его не показывает | никогда |
| Примечание студента | `request.note`, страница пишет «Примечание: …» | если студент его написал |
| Срок изготовления | `request.dueDate` | с перехода в «В работе» |
| Срок получения | `request.pickupUntil` | только с перехода в «Готова» |
| День выдачи | `request.issuedOn` | с «Выдана» |
| Причина отклонения | `request.rejectReason`, слова — `REJECT_REASON_LABELS` | при «Отклонена» |
| Кабинет | `REQUEST_KIND_INFO[kind].room` | всегда, зависит от вида |
| Где и как получить | `REQUEST_KIND_INFO[kind].pickup` | всегда, зависит от вида |
| Пройденные шаги | `request.events` — история статусов | всегда |

Время события, например «10:42», в образце сейчас есть. Есть ли оно в данных `getMyRequest` — проверь. Нет — убери из образца.

## Ловушки
- Правь инструментом правки, не командой оболочки: ошибка П-14 — команда испортила строку.
- Подразделы 5.1–5.12 не перенумеровывай и не переименовывай: на них стоят ссылки.
- Кодировка — UTF-8 без BOM, концы строк — LF, как в файлах. Свойства файлов в отчёте называй по выводу команды, не по памяти: ошибка П-19.
- Русские буквы в командах PowerShell 5.1 ломаются: скрипты на Python запускай из Git Bash, `PYTHONUTF8=1 uv run python …`.
- `uv run tools/check_all.py` ключей не разбирает: любой ключ, даже `--help`, запускает всю проверку — ошибка П-17. Запускай без ключей, один раз, в конце.
- Экран 360 и 320 px: ничего не уезжает вбок, текст переносится, а не обрезается.
- Данные в примерах вымышленные: кабинеты и даты — из продукта, они там вымышленные.
- Sonnet склонен дописывать «проверено»: пиши это только о том, что запускал, и приводи вывод.
- Береги лимит: читай названные строки, а не файлы целиком; команды собирай в один вызов; вывод обрезай.
