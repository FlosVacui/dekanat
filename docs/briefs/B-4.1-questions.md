## Ловушки
- **Правка ломает тест — верни прежний вид и вопрос.** Чужой тест после твоей правки красный: не правь тест, не подгоняй код вслепую, не оставляй красным. Верни кусок к прежнему виду и назови в отчёте тест, текст ошибки и своё предложение — ошибка ИИ 97. Особенно: `seed-cohort.test.ts`, `seed-reset.test.ts`, `notifications.spec.ts` и `m0.spec.ts` считают уведомления и заявки набора — новые уведомления набора могут сдвинуть их числа. Сдвинули — см. следующую ловушку «Числа набора»: разрешена только правка числа на размер твоих новых строк.
- **Числа набора.** Новые уведомления «Деканат ответил на вопрос» в наборе могут сдвинуть счёт уведомлений в `seed-cohort.test.ts`, `seed-reset.test.ts`, `notifications.spec.ts`, `m0.spec.ts`. **Разрешено** поправить в них только число, если сдвиг объясняется ровно новыми строками набора — на столько, сколько ты добавил; каждую правку — в отчёт «было → стало» с расчётом. Другая причина красного — правило выше: прежний вид и вопрос.
- **Новых текстов интерфейса не придумывай** — ни видимых, ни подписей для экранного чтеца, кроме названных в решениях. Нужен ещё текст — верни вопрос.
- **Владелец — из сессии, не из адреса и не из формы.** Номер студента в форме не передаётся. Сотрудник — только свой набор.
- **Свободный текст.** Никакого `dangerouslySetInnerHTML`, никакой разметки из текста; длина проверяется и в базе, и в слое, а не только `maxlength`.
- **Освежение — на сервере с посетителями.** Удаление — только вопросов студентов этого набора, которых нет в наборе данных, и только уведомлений со ссылкой на удалённый вопрос. Ошибка в условии сотрёт чужие данные на рабочем сайте: в модульном тесте — набор из двух студентов и заявка посетителя, которая должна остаться.
- **Миграция пойдёт на сервер** через `06-update.sh`: только добавление таблицы и индексов, без правки прежних таблиц.
- **Зелёный тест может ничего не проверять** — ошибка ИИ 115. Каждый цикл с проверками — с проверкой, что он прошёл больше нуля раз.
- **Тесты не зависят от дня недели и часа запуска** — ошибки ИИ 84, 115 и 120. Время бери с часов: `TZ='<+03>-3' date`. С 23:50 до 00:05 МСК сквозные тесты не запускай.
- **Сквозные тесты зависят от порядка файлов.** Доказательство для своего файла — прогон одного файла сразу после `npm run db:seed`, затем полный прогон.
- **После правки тестов — `(cd app && npx tsc --noEmit)`:** vitest типы не проверяет, а `next build` проверяет и тесты — ошибка ИИ 134.
- **Цвета и размеры — только переменными дизайн-системы.** Нужного нет — верни вопрос. Тёмную тему не включай. Новых зависимостей нет.
- **Машина нестабильна:** процессы Node.js падают с кодами `3221225477` и `3221225622` — [R-node-crashes](../research/R-node-crashes.md). Команды `npm`, `npx` и `node` — только с привязкой к ядрам, из Git Bash: `(cd app && cmd //c "start /b /wait /affinity FFFF0000 npm test")`. Голый `npx vitest` без `npm test` падает в глобальной настройке. `cmd start` не передаёт код возврата: итог читай по строкам `passed` и `failed`. Упала команда с таким кодом или Chromium с «Page crashed», а проваленных по существу проверок нет — повтори один раз и назови оба результата.
- **Общую проверку `tools/check_all.py` не запускай:** её прогонит оркестратор. У неё нет справки: любой параметр запускает полный прогон.
- **Команду с `cd` бери в скобки.** Файлы правь только инструментом записи или правки, не `sed -i`, не `mv`, не `cp` — ошибка ИИ 124. Heredoc нельзя — ни для файлов, ни для `python`, ни для `node`: скрипт запиши файлом в `%LOCALAPPDATA%\dekanat-runs\` и запусти оттуда.
- **Локальная база** — `127.0.0.1:5432`. Перед прогоном: полный путь `%LOCALAPPDATA%\dekanat-pg\pgsql\bin\pg_isready -h 127.0.0.1 -p 5432`, смотри код возврата. Не отвечает — не чини, верни в отчёте. Красные все тесты подряд — проверь право чтения: `states.spec.ts` и `gate3.spec.ts` отзывают его на время; возвращает `npm run db:migrate`. Файл `.env` не читай.
- Путь к репозиторию содержит кириллицу и пробелы: перед `-g` с кириллицей — `chcp 65001`; для `SCREENSHOT_DIR` — абсолютный путь в виде Windows через `cygpath -w`.
- **Перед отчётом проверь, что твоих процессов не осталось:** `node`, `next`, `playwright`, `chromium`, `bash`, `python` с папкой проекта, `.next` или `dekanat-runs` в командной строке. Останови только свои. Базу и чужие процессы `node` и `chrome` не трогай; процесс `uv run --no-project python scripts/check_all.py` — чужой.
