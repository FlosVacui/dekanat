Раздел 6 системы называет часть этих подписей иначе — оставь как в коде и назови расхождение в отчёте.
- **Тест упал из-за нового вида** — не правь тест и не подгоняй вид вслепую: верни в отчёте имя теста, текст ошибки и своё предложение.
- **Образ для сервера собирается из папки `app/` целиком;** папка `docs` в образ не попадает. Поэтому знак лежит копией в `app/public/`, а не читается из `docs/design/`. Docker на этой машине нет: образ ты не соберёшь, скажи в отчёте, что на сервере это не проверено.
- **Политика содержимого** в `app/next.config.ts`: картинки и шрифты — только со своего адреса, `data:` запрещён. Знак не встраивай строкой `data:`; обработку картинок сервером не включай — ставь знак обычным тегом `img` с размерами или компонентом картинки с признаком `unoptimized`. Линтер ругается на `img` — выбери второй способ.
- **Тёмную тему не включай:** класс `dark` никуда не ставь.
- **Тесты и снимки не зависят от дня недели запуска** — ошибка ИИ 84. Время бери с часов: `TZ='<+03>-3' date`. Между 23:50 и 00:05 МСК `npm run test:e2e` и `npm run screenshots` не запускай: база заполняется до полуночи, тесты считают ожидания после.
- **Машина нестабильна:** процессы Node.js падают с кодами `3221225477` и `3221225622` — [R-node-crashes](../research/R-node-crashes.md). Команда упала с таким кодом или оборвала соединение — `ECONNRESET`, уход на `/login`, «This page couldn’t load», — а проваленных по существу проверок нет: повтори один раз и назови оба результата. Упала дважды в одном месте — ищи причину.
- **Общую проверку `tools/check_all.py` не запускай:** её прогонит оркестратор после твоего отчёта.
- **Команду с `cd` бери в скобки** — ошибка 80. Файлы правь инструментом редактирования, а не командой оболочки; `cp` годится только для копий знака и лицензии.

- Собранные стили минифицированы: только `grep -F` — ошибка 83. Большие файлы читай по строкам.
