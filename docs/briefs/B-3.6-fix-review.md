## Ловушки
- **Файлы пишутся только инструментом записи.** Heredoc нельзя — ни для файлов, ни для `python`, ни для `node`: скрипт запиши файлом в `%LOCALAPPDATA%\dekanat-runs\` и запусти оттуда.
- **Команду с `cd` бери в скобки:** `(cd app && ...)`.
- **Машина нестабильна:** команды `npm` и `node` — только так, из Git Bash: `(cd app && cmd //c "start /b /wait /affinity FFFF0000 npm test")`. Упала с кодом `3221225477` или `3221225622`, оборвала соединение — `ECONNRESET`, уход на `/login` — или упал Chromium с «Page crashed» без проваленных по существу проверок: повтори один раз и назови оба результата. `cmd start` код возврата не передаёт: итог читай по строкам `passed` и `failed`.
- **Время** бери с часов: `TZ='<+03>-3' date`. Время начала и конца в шапке отчёта — с часов, не по памяти: ошибка ИИ 101.
- **Порядок файлов.** Тесты идут одним потоком по алфавиту: `m0.spec.ts` раньше `notifications.spec.ts` и оставляет в ленте старые напоминания. Поэтому доказательство R-3.6-1 — только прогон одного файла сразу после `npm run db:seed`.
- **Локальная база** — `127.0.0.1:5432`. Перед прогоном: полный путь `%LOCALAPPDATA%\dekanat-pg\pgsql\bin\pg_isready -h 127.0.0.1 -p 5432`, смотри код возврата. Не отвечает — не чини, верни в ответе. В конце верни набор: `npm run db:seed` с привязкой к ядрам.
- `npm run test:e2e` сам заполняет базу и собирает продукт; два прогона одновременно не запускай.
- **Перед отчётом проверь, что твоих процессов не осталось:** `node`, `next`, `playwright`, `chromium`, `bash`, `python` с папкой проекта или `dekanat-runs` в командной строке. Останови только свои. Базу и чужие процессы `node` и `chrome` не трогай.
