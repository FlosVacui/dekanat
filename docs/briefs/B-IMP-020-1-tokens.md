## Ловушки
- **Tailwind 4 и блок `@theme inline`.** Он лежит внизу файла переменных и должен попасть в сборку вместе с `:root`. Проверь на собранной странице, что утилита, например `bg-card`, дала правило, а не пропала молча.
- **Имена скруглений.** Утилиты называются `rounded-surface`, `rounded-control`, `rounded-pill`: объяснение — в комментарии над `@theme inline`.
- **Шрифта Nunito в продукте ещё нет** — это шаг 2 строки IMP-020. Сейчас работает запасной системный шрифт из того же списка. Пакет шрифта не ставь.
- **Экраны остаются на прежних классах** `neutral-*`, `bg-white`: их перевод — не этот шаг. Смешанный вид на снимках ожидаем; назови в отчёте места, где он режет глаз.
- **Тесты мерят зоны касания** не меньше 44×44: `app/tests/e2e/m0.spec.ts`, `requests.spec.ts`. Высота кнопки вырастет с 44 до 52 — тесты должны остаться зелёными без правок.
- **Процессы Node.js на этой машине иногда падают** с кодами `3221225477` и `3221225622`, причина не найдена: [R-node-crashes](../research/R-node-crashes.md). Команда упала с таким кодом, а проваленных проверок в выводе нет — повтори её один раз и назови повтор в отчёте. Проваленную проверку повтором не лечи.
- **Локальная база** — PostgreSQL на `127.0.0.1:5432`. Проверить: `pg_isready -h 127.0.0.1 -p 5432`; программы — в `%LOCALAPPDATA%\dekanat-pg\pgsql\bin`. Не отвечает — не чини, верни в отчёте.
- **`npm run test:e2e` и `npm run screenshots` сами заполняют базу и собирают продукт**; каждая идёт несколько минут. Одновременно их не запускай.
- **Путь к репозиторию содержит кириллицу и пробелы**; оболочка — Git Bash. Команду с `cd` бери в скобки, чтобы рабочая папка не сменилась: ошибка 80. Порты 3000, 3100 и 5432 могут быть заняты. Процессы, которые ты запустил, останови перед отчётом.
- **Файлы правь инструментом редактирования, а не командой оболочки**; копию `tokens.css` можно сделать командой `cp`, шапку — инструментом.
