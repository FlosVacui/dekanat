- **Блокировка — только в локальной тестовой базе и только на время теста.** Соединение владельца с блокировкой закрывай в `finally`. Запрос приложения, который ждёт блокировку дольше 10 секунд, база обрывает.
- **Отзыв права.** Процесс тестов погиб между отзывом и возвратом — право остаётся отозванным, `npm run db:seed` его не возвращает, возвращает `npm run db:migrate`. Красные все тесты подряд — проверь право: `%LOCALAPPDATA%\dekanat-runs\3.7-check-privilege.mjs`, запуск с переменной `REPO_DIR` — путь к репозиторию в виде Windows.
- **Зелёный тест может ничего не проверять** — ошибка ИИ 115. Каждый цикл с проверками — с проверкой, что он прошёл больше нуля раз. Скелет, которого первую секунду не видно, тест должен дождаться, а не проскочить.
- **Тесты и снимки не зависят от дня недели и часа запуска** — ошибки ИИ 84, 115 и 120. Время бери с часов: `TZ='<+03>-3' date`. Между 23:50 и 00:05 МСК сквозные тесты и скрипты снимков не запускай.
- **Сквозные тесты зависят от порядка файлов:** прежние файлы оставляют в базе свои заявки и уведомления. Доказательство для своего файла — прогон одного файла сразу после `npm run db:seed`, и затем полный прогон.
- **Цвета и размеры — только переменными дизайн-системы.** Нужного нет — верни вопрос. Тёмную тему не включай. Новых зависимостей нет.
- **Машина нестабильна:** процессы Node.js падают с кодами `3221225477` и `3221225622` — [R-node-crashes](../research/R-node-crashes.md). Команды `npm`, `npx` и `node` — только с привязкой к ядрам, из Git Bash: `(cd app && cmd //c "start /b /wait /affinity FFFF0000 npm test")`. `cmd start` не передаёт код возврата: итог читай по строкам `passed` и `failed`. Команда упала с таким кодом, оборвала соединение — `ECONNRESET`, уход на `/login`, «This page couldn’t load» — или упал Chromium с «Page crashed», а проваленных по существу проверок нет: повтори один раз и назови оба результата. Упала дважды в одном месте — ищи причину.
- **Общую проверку `tools/check_all.py` не запускай:** её прогонит оркестратор. У неё нет справки: любой параметр запускает полный прогон.
- **Команду с `cd` бери в скобки** — ошибки ИИ 80 и 104. Файлы правь и переноси только инструментом записи или редактирования, а не командой оболочки: `mv`, `cp`, `sed -i` для файлов репозитория нельзя — ошибка ИИ 124. Heredoc нельзя — ни для файлов, ни для `python`, ни для `node`: свой скрипт запиши файлом в `%LOCALAPPDATA%\dekanat-runs\` инструментом записи и запусти оттуда. Вывод команд в файл журнала вне репозитория перенаправлять можно.
- **Локальная база** — `127.0.0.1:5432`. Перед прогоном: полный путь `%LOCALAPPDATA%\dekanat-pg\pgsql\bin\pg_isready -h 127.0.0.1 -p 5432`, смотри код возврата. Не отвечает — не чини, верни в отчёте. Файл `.env` не читай.
- `npm run test:e2e` и скрипты снимков сами заполняют базу и собирают продукт; одновременно их не запускай. Свой сервер поднимай на отдельном порту и останови.
- Собранные стили минифицированы: только `grep -F` — ошибка ИИ 83. Большие файлы читай по строкам. Путь к репозиторию содержит кириллицу и пробелы. `tar` в Git Bash — только с `--force-local`.
- **Перед отчётом проверь, что твоих процессов не осталось:** `node`, `next`, `playwright`, `chromium`, `bash`, `python` с папкой проекта в командной строке. Останови только свои. Базу и чужие процессы `node` и `chrome` не трогай: на машине идёт другой проект.
