Команды `npm` и `node` — только с привязкой к ядрам, из Git Bash: `(cd app && cmd //c "start /b /wait /affinity FFFF0000 npm test")`. Команда упала с таким кодом, оборвала соединение — `ECONNRESET`, уход на `/login`, «This page couldn’t load» — или упал Chromium с «Page crashed», а проваленных по существу проверок нет: повтори один раз и назови оба результата. Упала дважды в одном месте — ищи причину.
- **Общую проверку `tools/check_all.py` не запускай:** её прогонит оркестратор. У неё нет справки: любой параметр запускает полный прогон.
- **Команду с `cd` бери в скобки** — ошибки ИИ 80 и 104. Файлы правь только инструментом записи или редактирования, а не командой оболочки. Heredoc нельзя — ни для файлов, ни для `python`, ни для `node`: свой скрипт запиши файлом в `%LOCALAPPDATA%\dekanat-runs\` инструментом записи и запусти оттуда. Вывод команд в файл журнала вне репозитория перенаправлять можно.
- **Локальная база** — `127.0.0.1:5432`. Перед прогоном: полный путь `%LOCALAPPDATA%\dekanat-pg\pgsql\bin\pg_isready -h 127.0.0.1 -p 5432`, смотри код возврата. Не отвечает — не чини, верни в отчёте.
- `npm run test:e2e` и скрипты снимков сами заполняют базу и собирают продукт; одновременно их не запускай. Свой сервер поднимай на отдельном порту и останови.
- Собранные стили минифицированы: только `grep -F` — ошибка ИИ 83. Большие файлы читай по строкам. Путь к репозиторию содержит кириллицу и пробелы.
- **Перед отчётом проверь, что твоих процессов не осталось:** `node`, `next`, `playwright`, `chromium`, `bash`, `python` с папкой проекта или `dekanat-runs` в командной строке. Останови только свои. Базу и чужие процессы `node` и `chrome` не трогай: на машине идёт другой проект.
