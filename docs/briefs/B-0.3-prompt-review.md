# Задание: 0.3 Ревью промптов — правила сессии, роли, команды

## Роль, модель, effort
`prompt-reviewer` — Sonnet 5.5 / high. Раунд 1.

## Участник и ветка
А; локальный `main`. Удалённого репозитория ещё нет.

## Цель
Независимо проверить файлы, которые управляют ИИ-агентами проекта, до того как по ним начнут работать три человека и субагенты. Эти файлы оценивает жюри (критерий «масштаб использования нейротехнологий»: качество промптов, структура файлов для ИИ-агентов). Их написал оркестратор без ревью — это замечание [IMP-004](../ISSUES.md).

## Входные данные
- Пакет в `tracker.yaml`: 0.3, срок 11.11.
- Критерий готовности пакета из `docs/ROADMAP.md`: «Каждая роль отвечает на „что можно менять и чего нельзя“».
- Требования из матрицы: КО-2.
- Связанные развилки и ADR: нет.
- Ресерч: нет.
- Ответы внешних нейросетей: нет.
- Образец для подражания: нет.

## Что сделать
1. Прочитай проверяемые файлы целиком:
   - `CLAUDE.md`;
   - все десять файлов `.claude/agents/*.md`;
   - `.claude/skills/start/SKILL.md`, `.claude/skills/handoff/SKILL.md`, `.claude/skills/gate/SKILL.md`;
   - `.claude/settings.json`.
2. Прочитай то, с чем их сверять: `docs/PROCESS.md`, `docs/ROADMAP.md`, `docs/DECISIONS.md`, `docs/ONBOARDING.md`, `docs/glossary.md`, `docs/templates/`, `docs/tracker/README.md`.
3. Проверь каждый файл по списку из своей роли: ясность, полнота, противоречия, исполнимость, риски, лишнее.
4. Отдельно проверь:
   - таблица ролей в `docs/PROCESS.md` против файлов ролей: модель, effort, что можно менять, чего нельзя;
   - шаги `CLAUDE.md` «В начале каждой сессии» и «В конце каждой сессии» против команд `/start` и `/handoff` и раздела «Смены» в `docs/PROCESS.md`;
   - хватает ли каждой роли инструментов из поля `tools` для её работы и нет ли лишних;
   - каждую команду и каждый путь, на которые ссылаются проверяемые файлы: существуют ли они в репозитории.
5. Напиши отчёт.
