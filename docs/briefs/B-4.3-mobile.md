## Цель
Критерий пакета 4.3 в [ROADMAP](../ROADMAP.md) — «пороги из ресерча 1.3 выполнены на телефоне». На воротах 3 проверка [MOB-3.10](../reviews/MOB-3.10.md) мерила скорость без замедления сети и не проверяла ширину меньше 360 px, положение «лёжа», крупный шрифт и тёмную тему. Нужно закрыть эти пробелы числами и сказать по каждому порогу: выполнен, не выполнен, не измерить. Требования — ЗД-3, ЗД-4 и ТР-4 в `docs/REQUIREMENTS.md`, критерии жюри КО-3 и КО-4.

## Что сделать
**Промежуточный итог — после каждого пункта и после последнего прогона:** две-три строки в `%LOCALAPPDATA%\dekanat-runs\mob-4.3-progress.md`, файл перезаписывай целиком инструментом записи.

1. **Новый файл теста** `app/tests/e2e/mobile-4.3.spec.ts`. Файл только читает: не подаёт заявок, не меняет статус, не отмечает уведомления прочитанными — сквозные тесты зависят от порядка файлов. Экраны студента: вход, «Сегодня», «Расписание», «Успеваемость» с раскрытым «Все работы (N)» и страница предмета `/grades/[id]`, «Заявки» и новая заявка без отправки, «Уведомления», «Профиль», «Идеи и планы» `/ideas`. На 1024 и 1280 px — колонка разделов и плитки на «Сегодня»: фронтенд переработан по отзывам разработчиков и их одногруппников, 18.11. Сотрудник: список заявок с фильтром и поиском, экран заявки без «Сохранить». Пакет 4.1 «связь с деканатом» — если он в ветке: есть ли он, скажет сообщение запуска.
2. **Скорость на замедленной сети.** В Chromium через CDP: `Network.emulateNetworkConditions` с числами Н10.3 и `Emulation.setCPUThrottlingRate` 4. На 360×800, пустой кэш, по три прогона каждого экрана из пункта 1: LCP и CLS — через `PerformanceObserver` на странице; вес скриптов в сжатом виде — по `transferSize` ресурсов. В отчёт — таблица: все числа, медиана, порог, итог. Переход по вкладке нижней панели с «Сегодня» на «Расписание», «Заявки», «Профиль» — CLS отдельно: это IMP-038.
3. **Ширины и положение.** 320×640, 360×800, 390×844, «лёжа» 800×360; 1023 и 1024 px — граница вида на компьютере; 1280 px. На каждом экране: нет прокрутки вбок; цели не меньше 24×24 px, список меньше 44×44 — с размером; шапка и нижняя панель не закрывают содержимое при прокрутке до конца; на телефоне ссылка «Идеи и планы» над подвалом не закрыта нижней панелью; колонка разделов — 220 px на 1024 и 240 px на 1280, строка шапки с семестром на 320 px не обрезана. Проверки — точным шаблоном, не подстрокой: ошибка ИИ 125.
4. **Крупный шрифт.** Шрифт страницы 200 %: на 360 px нет прокрутки вбок, текст не обрезан, кнопки не накладываются. Как увеличен шрифт — опиши в отчёте.
5. **Доступность.**
   - порядок фокуса клавишей Tab на «Сегодня», «Успеваемости», новой заявке и у сотрудника — по шагам; видна ли рамка фокуса — по снимкам, а не по наличию любой тени: MOB-3.10 так ошибся;

   - подписи полей и `autocomplete` на входе и в новой заявке;
   - контраст текста и рамок полей; `@axe-core/playwright` есть в `app/package.json` — правила `color-contrast` и `target-size`; нет — своя проверка и строка «axe нет». Ставить пакеты нельзя.
6. **Тёмная тема.** Есть ли она в продукте: что переключает её и работает ли `prefers-color-scheme: dark`. Нет — строка «тёмной темы в продукте нет: где проверено». Есть — контраст и снимки 360 px.
7. **Повторно с числами:** R-3.10-101 и R-3.10-103 — положение блоков в px на 360×800; «Сегодня» и «Успеваемость» переделаны 18.11 — мерь заново, не сравнивай с MOB-3.10 без оговорки; R-3.5-6 — число рамочных кнопок на ленте «Все».
8. **Снимки** — папка `docs/evidence/screenshots/<дата запуска>-4.3/`, дата с часов. Каждый экран: 320, 360 и 1280 px, «лёжа», шрифт 200 %. Имя говорит, что на снимке: `320-grades.png`. Неудачный снимок получает `fail-` в начале и не удаляется. Папку задавай переменной `SCREENSHOT_DIR`, как в `mobile-m1.spec.ts`; без неё — временная папка в `%LOCALAPPDATA%\dekanat-runs\`. 9. **Прогон.** С привязкой к ядрам, см. «Ловушки»: сначала свой файл одним прогоном сразу после `npm run db:seed`; затем `npm run test:e2e` целиком — новый файл не должен ломать чужие тесты. Время с часов в начале и конце каждого прогона — в отчёт. Общую проверку `tools/check_all.py` не запускай.

Серьёзность: блокирующее, существенное, незначительное, предложение. Каждое замечание — со снимком или шагами. Колонку «Решение оркестратора» оставь пустой. ## Ловушки
- **Файлы пишутся только инструментами записи и правки, не `sed -i`.** Heredoc нельзя — ни для файлов, ни для `python`, ни для `node`: скрипт — файлом в `%LOCALAPPDATA%\dekanat-runs\`, запуск оттуда — ошибка ИИ 104.
- **Команду с `cd` бери в скобки:** `(cd app && ...)`.
- **Машина нестабильна:** процессы Node.js падают с кодами `3221225477` и `3221225622`. Команды `npm`, `npx`, `node` — только так, из Git Bash: `(cd app && cmd //c "start /b /wait /affinity FFFF0000 npx playwright test tests/e2e/mobile-4.3.spec.ts --reporter=line")`. `cmd start` не передаёт код возврата: итог читай по строкам `passed` и `failed`. Упал процесс с таким кодом или Chromium с «Page crashed» без проваленных по существу проверок — повтори один раз и назови оба результата.
- **После правки теста — `(cd app && npx tsc --noEmit)`:** Playwright типы не проверяет, а `next build` в полном сквозном прогоне проверяет и тесты — ошибка ИИ 134.
- **Сервер для тестов** — собранное приложение `next start`, помощники `app/tests/e2e/helpers/server.ts`, порт 3100. Замеры скорости — на этой сборке; режим разработки не запускай.
- **Локальная база** — `127.0.0.1:5432`. Перед прогоном: полный путь `%LOCALAPPDATA%\dekanat-pg\pgsql\bin\pg_isready -h 127.0.0.1 -p 5432`, смотри код возврата. Не отвечает — не чини, верни в ответе.
- **Красные все тесты подряд** — проверь право чтения таблиц: `states.spec.ts` и `gate3.spec.ts` отзывают его на время. Право возвращает `npm run db:migrate`, а не `npm run db:seed`. Перед отчётом — `npm run db:seed`.
- **День недели.** Твой файл не должен зависеть от дня недели: в день без пар экран расписания пуст — это не ошибка. Красный `schedule.spec.ts` или `grades.spec.ts` — сначала R-3.2-1 в [RV-3.2-1](../reviews/RV-3.2-1.md) и пункт 9 [RV-3.3-1](../reviews/RV-3.3-1.md).
- **Время бери с часов:** `TZ='<+03>-3' date`. В шапке отчёта — с часов, не по памяти: ошибки ИИ 101 и 129. С 23:50 до 00:05 МСК сквозные тесты не запускай.
- **Зелёный тест может ничего не проверять** — ошибка ИИ 115. Тест, который только записывает числа, так и назови в отчёте: MOB-3.10 признал это за своим тестом «главное действие видно».
- **`.env` не читать.**
- **Проверка чистоты** `tools/check_clean.py`: в отчёте не пиши абсолютных путей этой машины и записей вида «пакет@версия». На снимках — только вымышленные данные.
- Путь к репозиторию содержит кириллицу и пробелы. Кириллица в `-g` через `cmd` может не найти тесты: перед запуском — `chcp 65001`. Для `SCREENSHOT_DIR` — абсолютный путь в виде Windows: `cygpath -w`.
- **Перед отчётом проверь, что твоих процессов не осталось:** `node`, `next`, `playwright`, `chromium`, `bash`, `python` с папкой проекта, `.next` или `dekanat-runs` в командной строке. Останови только свои. Чужие `node` и `chrome` не трогай: на машине идёт другой проект; процесс `uv run --no-project python scripts/check_all.py` — тоже чужой.
