# B-ideas-C — режим жюри и страница «Как это сделано»

19.11.2026. Исполнитель — субагент общего назначения с ролью `builder` (`.claude/agents/builder.md`), Sonnet 5.5 / high. Решение пользователя (участник А) 19.11.

## Что сделать
1. **Режим жюри** (идея №89). Плавающая панель внизу справа (на телефоне — над нижней панелью навигации, не закрывает её и фокус) со сценарием на 60 секунд:
   1. «Студент → Сегодня: что ждёт студента» — `/`
   2. «Успеваемость: долг и допуск» — `/grades`
   3. «Справка за секунду с QR» — `/requests/new`
   4. «Заявки: что требует ответа» — `/requests`
   5. «Сотрудник: заявки, просроченные наверху» — `/staff/requests`
   6. «Как это сделано» — `/process`
   Каждый шаг — ссылка. Текущий шаг подсвечен по адресу. Кнопка «Скрыть»; свернутое состояние — маленькая кнопка «Сценарий для жюри». Состояние в `localStorage` внутри `try/catch`. Без паролей и без входа под чужим логином. Если демо-логины уже показаны на странице входа или в README — шаг «Войдите как студент» ведёт на `/login`, логины не дублируй. Клиентский компонент `app/src/components/jury/jury-panel.tsx`, подключение одной строкой в `student-shell.tsx` и `staff-shell.tsx`. Показ по умолчанию — да; можно выключить переменной `NEXT_PUBLIC_JURY_MODE=off`.
2. **Страница «Как это сделано»** (идея №90) — `/process`, доступна студенту и сотруднику (и без входа, если это просто — по правилам открытых маршрутов). Содержание — только факты из репозитория, ничего не придумывать:
   - как работала команда: роли и смены (из `docs/PROCESS.md`), число смен и записей журнала (посчитай по `docs/history/JOURNAL.md`);
   - ошибки ИИ: число записей в `docs/evidence/ai-errors.md` и 3 показательные — заголовок и одна строка «как поймали», своими словами;
   - промпты: число записей в `prompts/INDEX.md`;
   - инструменты: из `docs/evidence/tools.md` — список названий;
   - ссылки на файлы в GitHub `https://github.com/FlosVacui/dekanat/blob/main/<путь>` с пометкой «Репозиторий откроется 21.11».
   Числа считай один раз при написании и вписывай в страницу как статичный текст с датой «на 19.11.2026»; в отчёте приведи, как считал (команда и вывод). Страница — серверный компонент, оформление на существующих токенах и компонентах.
   Ссылку «Как это сделано» добавь в меню профиля или в подвал оболочки — одной строкой.
