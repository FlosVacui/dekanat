# Задание: 2.6 Правки по аудиту безопасности SEC-2.6

Задание самодостаточное: чата оркестратора ты не видел. Аудит провёл другой агент; его отчёт — [SEC-2.6](../reviews/SEC-2.6.md).

## Роль, модель, effort
`builder` — Sonnet 5.5 / high.

## Участник и ветка
А; ветка `feat/2.6-security`. Ветку не переключай.

## Цель
Закрыть четыре замечания аудита так, чтобы атакующие тесты аудитора прошли без пометки «ожидаемо падает». Это критерий жюри о безопасности и требования ТР-9.1…ТР-9.3.

## Входные данные
- Пакет в `tracker.yaml`: 2.6, срок 14.11.
- Отчёт аудита: [SEC-2.6](../reviews/SEC-2.6.md), раздел «Замечания»: R-2.6-1…R-2.6-4. Решение по каждому — в последней колонке.
- ADR: [ADR-0004](../adr/ADR-0004-secrets-config.md), раздел «Заголовки»; [ADR-0002](../adr/ADR-0002-data-access.md), правило о действующем лице; [ADR-0003](../adr/ADR-0003-auth-sessions.md), раздел «Пароль».
- Ресерч: [R-1.5](../research/R-1.5.md), находка F13 — таблица наборов scrypt; проверки З-02, В-01.
- Ответы внешних нейросетей: нет. Образец: нет.

## Что сделать
1. **R-2.6-1 — заголовки защиты.** В `app/next.config.ts` через `headers()` на все адреса:
   - `X-Content-Type-Options: nosniff`;
   - `Referrer-Policy: strict-origin-when-cross-origin` или строже;
   - `Permissions-Policy` — камера, микрофон, геолокация и оплата выключены;
   - `X-Frame-Options: DENY`;
   - `Content-Security-Policy`: `default-src 'self'`; `frame-ancestors 'none'`; `object-src 'none'`; `base-uri 'self'`; `form-action 'self'`; скрипты и стили — `'self' 'unsafe-inline'`. В рабочей сборке `unsafe-eval` нет. Режиму разработки `unsafe-eval` нужен: добавляй его только при `NODE_ENV !== 'production'`.
   - Политика с одноразовой меткой здесь не делается: [IMP-017](../ISSUES.md). Промежуточный слой не добавляй.
   - Заголовок `Cache-Control` личных ответов не трогай: проверка З-06 сейчас проходит.
   - Устаревший комментарий в начале `next.config.ts` поправь.
   - Сними пометку `test.fail` с теста `R-2.6-1 З-02` в `app/tests/security/headers-and-build.spec.ts`. Утверждения теста не меняй. Тест требует значения, которого нет в этом списке, — поставь его; оно противоречит списку — остановись и верни вопрос.
   - Пройди сквозной тест: кабинет под политикой должен работать — вход, заявка, смена статуса. В консоли браузера не должно быть отказов политики; проверь это в своём прогоне и напиши в отчёте, как проверил.
2. **R-2.6-2 — действующее лицо.** В `app/src/server/auth/session.ts` проверка `isActor` сверяет закрытое поле класса, а не `instanceof`: например, статический метод `Actor.is(value)` с `#sealed in value`. Объект, собранный через `Object.create(Actor.prototype)` или `Object.setPrototypeOf`, получает `ForbiddenError`. Поправь комментарии рядом. Сними пометку `test.fails` с двух тестов `R-2.6-2` в `app/tests/security/dal-attacks.test.ts`; утверждения не меняй.
3. **R-2.6-4 — нижняя граница параметров хеша.** В `parseHash`, `app/src/server/auth/password.ts`: строка принимается, только если r ≥ 8 и пара (N, p) не ниже одной из строк таблицы F13 в R-1.5. Набор проекта N = 2^16, r = 8, p = 2 проходит. Добавь модульный тест в `app/tests/unit/password.test.ts`: строка с N = 2^14, r = 8, p = 1 отклоняется; строка проекта принимается. Перехеширования при входе не делай.
4. **R-2.6-3 — `.dockerignore`.** Замени строку `tests` на `**/tests`. Больше в файле ничего не меняй. `tsconfig.json` не трогай.
5. **Прогоны** из папки `app/`: `npm run typecheck`, `npm run lint`, `npm test`, `npm run test:e2e`. Затем из корня: `uv run tools/check_all.py`.

## Ловушки
- **Локальная база** работает на `127.0.0.1:5432`. Не останавливай её и сам не запускай. Не отвечает — верни это в отчёте.
- **`.env` не читать.** Команды `npm …` сами подают окружение.
- **Тест с пометкой, который начал проходить, краснеет** — так и задумано: пометку снимают вместе с правкой, не раньше.
- **Политика содержимого и Next.js.** Без `'unsafe-inline'` у скриптов страница не оживёт: Next.js вставляет свои скрипты. Шрифты и картинки — только свои; понадобится `data:` у картинок или шрифтов — добавь и скажи в отчёте, зачем.
- **`npm run test:e2e`** пересобирает приложение и возвращает вымышленные данные в исходное состояние. Порт 3100 занят — останови свой процесс, чужие не трогай.
- **Windows:** путь с кириллицей и пробелами. Файлы правь инструментом редактирования, а не командой оболочки с вложенным текстом.
