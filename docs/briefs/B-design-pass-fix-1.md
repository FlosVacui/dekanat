## Как гонять e2e в этой песочнице
Сборка: `cd app && npm run build`. Каждый файл — отдельно и на своём порту, со свежими данными:
`npm run db:seed && E2E_PORT=33NN npx playwright test -c playwright.local.config.ts tests/e2e/<файл>` (локальный конфиг с системным Chrome уже лежит в `app/`, в git его не добавлять), после прогона — `pkill -f "next start"`.
Известное свойство песочницы: остановка сервера после тестов падает «Не дождались: остановки сервера», а следующий `startServer` в том же файле — «Порт занят». Это не ошибка продукта: такие падения не чинить. Если в файле несколько `startServer`, проверь каждую группу отдельным прогоном с `--grep`.
Логи прошлого прогона: `/tmp/e2e-<файл>.log`.
