## Исполнитель Р — помощник по положениям (идея №21)
Файлы: `src/lib/regulations/**` (новое), `src/app/assistant/**` (новое), `src/app/rules/**` (новое), `src/server/ai.ts` (дописать), `src/app/questions/**` (только ссылка на помощника и предзаполнение вопроса из помощника), навигация студента — найди, где задаются пункты «Разделы» на компьютере и меню профиля, добавь пункт «Помощник» (не в нижнюю панель вкладок, их четыре), `src/components/jury/steps.ts` (подсказка шага 4: «…или спросите помощника по правилам»), `prompts/P-AI-03-regulations.md`, `prompts/INDEX.md` (одна строка), тесты.
1. **Положение.** Вымышленное «Положение о студентах факультета» на 35–45 пунктов с номерами вида `4.3`, разделы: обучение и расписание; промежуточная аттестация и пересдачи; стипендии и матпомощь; справки и документы; академический отпуск, перевод, восстановление; общежитие; поведение и взыскания. Разумные, правдоподобные, но явно учебные формулировки. Хранить как данные в TypeScript (массив пунктов: номер, раздел, заголовок, текст). Страница `/rules` — всё положение с якорями `#p-4-3`, плашка «Учебный пример для прототипа, не настоящий документ вуза». Доступна студенту и сотруднику.
2. **Поиск пунктов.** Чистая функция: нормализация русского текста (нижний регистр, ё→е, простая обрезка окончаний до основы 4–6 букв), счёт совпадений по заголовку (вес 2) и тексту (вес 1), топ-5 с порогом. Без зависимостей.
3. **Ответ.** `/assistant`: поле вопроса (до 300 знаков), кнопка «Спросить», 4 примера-подсказки («Можно ли пересдать экзамен дважды?», «Как получить справку в военкомат?», «Когда назначают повышенную стипендию?», «Как оформить академический отпуск?»). Сервер: найти пункты → если ИИ включён, модель отвечает только по переданным пунктам, коротко (до 700 знаков), и возвращает JSON `{answer, cited: ["4.3", …], confident: bool}`; проверить, что все `cited` есть среди переданных, иначе отбросить лишние; нет пунктов или `confident=false` → честное «В положении ответа не нашёл». Без ИИ (или ошибка) — показать найденные пункты без пересказа: «Вот что нашлось в положении».
   Под ответом: ссылки «п. 4.3» на `/rules#p-4-3`, кнопка «Не помогло — спросить деканат» (ведёт на создание вопроса с подставленным текстом), подпись «Ответ подготовлен ИИ по положению. Проверьте пункт по ссылке» или «Подбор по ключевым словам».
   Форма работает без JS (server action или GET). Лимиты вызовов модели — те же, что в `ai.ts`. В промпт уходит только текст вопроса и пункты.
4. Промпт модели — дословно в `prompts/P-AI-03-regulations.md`; unit-тест сверяет его с константой (как у P-AI-01/02).
5. Тесты: unit — поиск (10+ вопросов → ожидаемые пункты в топ-3), проверка `cited`, запасной путь без ИИ, подмена `fetch`. e2e `tests/e2e/assistant.spec.ts`: пример-вопрос → ответ с ссылкой на пункт (без ключа — путь «Вот что нашлось»), переход на `/rules#…`, «Не помогло» → форма вопроса с текстом; 360 px без прокрутки вбок.
