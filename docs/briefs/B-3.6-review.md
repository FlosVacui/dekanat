## Ловушки
- **Файлы пишутся только инструментом записи.** Heredoc нельзя — ни для файлов, ни для `python`, ни для `node`: скрипт запиши файлом в `%LOCALAPPDATA%\dekanat-runs\` инструментом записи и запусти оттуда — ошибка ИИ 104.
- **Команду с `cd` бери в скобки:** `(cd app && ...)` — ошибки ИИ 80 и 104.
- **Машина нестабильна:** процессы Node.js падают с кодами `3221225477` и `3221225622`. Команды `npm` и `node` — только так, из Git Bash: `(cd app && cmd //c "start /b /wait /affinity FFFF0000 npm test")`. Упала с таким кодом, оборвала соединение — `ECONNRESET`, уход на `/login` — или упал Chromium с «Page crashed» без проваленных по существу проверок: повтори один раз и назови оба результата.

Красный тест «событие рождает уведомление» в этот час — замечание к правке, а не сбой машины.
- **День недели.** Красный `schedule.spec.ts` или шаг 3 теста `m0.spec.ts` — сначала прочитай R-3.2-1 в [RV-3.2-1](../reviews/RV-3.2-1.md); красный `grades.spec.ts` — пункт 9 отчёта [RV-3.3-1](../reviews/RV-3.3-1.md). Находку верни отдельной строкой.
