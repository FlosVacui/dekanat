## Ловушки
- **Файлы пишутся только инструментом записи.** Heredoc нельзя — ни для файлов, ни для `python`, ни для `node`: скрипт Playwright запиши файлом в `%LOCALAPPDATA%\dekanat-runs\` и запусти оттуда — ошибка ИИ 104.
- **Команду с `cd` бери в скобки:** `(cd app && ...)`.
- **Машина нестабильна:** команды `npm`, `npx`, `node` — только так, из Git Bash: `(cd app && cmd //c "start /b /wait /affinity FFFF0000 npm run build")`. Сервер — в фоне той же командой с `npm run start -- -p 3000`. Упал процесс с кодом `3221225477` или `3221225622` — повтори один раз и назови это в отчёте.
- **Playwright** уже стоит в `app/node_modules`; браузер Chromium — в кэше пользователя. Скрипт запускай из папки `app/`, чтобы он нашёл пакет.
- **Локальная база** — `127.0.0.1:5432`. Перед стартом: полный путь `%LOCALAPPDATA%\dekanat-pg\pgsql\bin\pg_isready -h 127.0.0.1 -p 5432`, смотри код возврата. Не отвечает — не чини, верни в ответе.
- **Подача заявки и смена статуса меняют базу.** Перед отчётом верни набор: `(cd app && cmd //c "start /b /wait /affinity FFFF0000 npm run db:seed")`.
- **`.env` не читать.**
- **Время бери с часов:** `TZ='<+03>-3' date`. Время начала и конца в шапке отчёта — с часов: ошибки ИИ 101 и 129.
- **Проверка чистоты** `tools/check_clean.py`: в отчёте не пиши абсолютных путей этой машины и записей вида «пакет@версия».
- Путь к репозиторию содержит кириллицу и пробелы.
- **Перед отчётом проверь, что твоих процессов не осталось:** `node`, `next`, `chromium`, `bash`, `python` с папкой проекта или `dekanat-runs` в командной строке, сервер на порту 3000. Останови только свои. Чужие `node` и `chrome` не трогай: на машине идёт другой проект.
- В `git status` могут быть правки в `docs/` и `prompts/`, новые тесты и снимки: это работа команды, не твоя.
