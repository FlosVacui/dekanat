## Цель
Студент видит, что у него непрочитанного: число у колокольчика, строка на экране и пометка «Новое». Касание уведомления ведёт к тому, о чём оно, и снимает пометку. Новости и объявления деканата и напоминания стоят в одной ленте с фильтром. Событие в кабинете — смена статуса заявки сотрудником — рождает уведомление, и это доказано сквозным тестом. Критерий плана: «Непрочитанное видно; событие в кабинете рождает уведомление». Требование ЯД-5.

## Ловушки
- **Правка ломает тест — верни прежний вид и вопрос.** Чужой тест после твоей правки красный: не правь тест, не подгоняй код вслепую и не оставляй тест красным. Верни этот кусок к прежнему виду, а в отчёте назови имя теста, текст ошибки и своё предложение — ошибка ИИ 97. Существующие тесты ты не правишь.
- **Новых текстов интерфейса не придумывай.** Тексты — только из этого задания и те, что уже есть на экране. Нужен ещё текст, в том числе подпись для экранного чтеца, — верни вопрос в отчёте: в прошлом заходе исполнитель добавил два текста сам, замечание R-3.7-5.
- **Отметку нельзя ставить переходом по ссылке.** Next.js заранее подгружает ссылки: запрос GET, который отмечает запись, отметит всё, что видно на экране. Отметка — только отправкой формы.
- **Адрес перехода — только из базы и только внутренний.** Адрес из формы или из параметра — открытое перенаправление. Номер записи из формы не определяет, чьи это данные: студента сервер берёт из сессии.
- **Разный ответ на «чужое» и «нет такого» — утечка.** Тест это ловит.
- **Тесты держатся за разметку.** Не меняй: `data-testid="bell-count"` и подпись колокольчика «Уведомления, непрочитанных: N» — файл шапки не твой; заголовок экрана «Уведомления»; текст «Расчётная работа №3» должен остаться на `/notifications` без фильтра — метка теста безопасности.
- **Число у колокольчика вырастет** на непрочитанные объявления. Тесты `dal-staff.test.ts` и `dal-attacks.test.ts` сверяют разницу, а не число; если какой-то тест ждёт точное число — действуй по первой ловушке.
- **Освежение набора** — `npm run db:refresh` — прочитанность не трогает; полное заполнение — `npm run db:seed` — возвращает её к набору. Набор и схему не меняй.
- **Цвета и размеры — только переменными дизайн-системы:** `app/src/app/tokens.css`, блок `@theme inline`. Нужного нет — верни вопрос. Тёмную тему не включай. Новых зависимостей нет.
- **Тесты и снимки не зависят от дня недели запуска** — ошибка ИИ 84. Время бери с часов: `TZ='<+03>-3' date`. Между 23:50 и 00:05 МСК `npm run test:e2e` и скрипты снимков не запускай.
- **Машина нестабильна:** процессы Node.js падают с кодами `3221225477` и `3221225622` — [R-node-crashes](../research/R-node-crashes.md). Команды `npm` и `node` — только с привязкой к ядрам, из Git Bash: `(cd app && cmd //c "start /b /wait /affinity FFFF0000 npm test")`. Команда упала с таким кодом, оборвала соединение — `ECONNRESET`, уход на `/login`, «This page couldn’t load» — или упал Chromium с «Page crashed», а проваленных по существу проверок нет: повтори один раз и назови оба результата. Упала дважды в одном месте — ищи причину.
- **Общую проверку `tools/check_all.py` не запускай:** её прогонит оркестратор после твоего отчёта.
- **Команду с `cd` бери в скобки** — ошибки ИИ 80 и 104. Файлы правь только инструментом записи или редактирования, а не командой оболочки. Heredoc нельзя — ни для файлов, ни для `python`, ни для `node`: свой скрипт запиши файлом в `%LOCALAPPDATA%\dekanat-runs\` инструментом записи и запусти оттуда. Вывод команд в файл журнала вне репозитория перенаправлять можно.
- **Локальная база** — `127.0.0.1:5432`. Перед прогоном: полный путь `%LOCALAPPDATA%\dekanat-pg\pgsql\bin\pg_isready -h 127.0.0.1 -p 5432`, смотри код возврата. Не отвечает — не чини, верни в отчёте.
- `npm run test:e2e` и скрипты снимков сами заполняют базу и собирают продукт; одновременно их не запускай. Свой сервер поднимай на отдельном порту и останови.
- Собранные стили минифицированы: только `grep -F` — ошибка ИИ 83. Большие файлы читай по строкам. Путь к репозиторию содержит кириллицу и пробелы.
- **Перед отчётом проверь, что твоих процессов не осталось:** `node`, `next`, `playwright`, `chromium`, `bash`, `python` с папкой проекта в командной строке. Останови только свои. Базу и чужие процессы `node` и `chrome` не трогай: на машине идёт другой проект.
