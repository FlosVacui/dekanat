## Ловушки
- **Правка ломает тест вне шага 5 — верни прежний вид и вопрос.** Не подгоняй код вслепую и не оставляй тест красным; в отчёте — имя теста, текст ошибки, предложение — ошибка ИИ 97.
- **Новых текстов интерфейса не придумывай** — ни видимых, ни подписей для экранного чтеца. Тексты — из раздела решений, из этого задания и уже стоящие на экране. Нужен ещё текст — поставь прежний и верни вопрос.
- **Длина слова плашки.** В 5.4 стоит «слово — одно или два, до 14 знаков» и `white-space: nowrap`. Утверждённые «Замена преподавателя» — 20 знаков, «Другая аудитория» — 16; прежняя «Сменился преподаватель» тоже была длиннее. Тексты не сокращай: они утверждены участником А. Проверь на 360 px, что плашка в панели не обрезается и не вызывает прокрутку вбок, и в шаге 7 поправь правило 5.4 под эти слова. Не помещается — верни вопрос.
- **Изменение — не только цветом:** у плашки всегда значок и слово; у отмены — зачёркивание и «Занятие не состоится».
- **Зелёный тест может ничего не проверять** — ошибка ИИ 115: проверка прокрутки должна сначала убедиться, что страница действительно прокручена до нажатия.
- **Тесты не зависят от дня недели и часа** — ошибки 84, 115 и 120. «Завтра» и «Сегодня» в модульных тестах — от переданной даты, не от часов машины. Время бери с часов: `TZ='<+03>-3' date`. С 23:50 до 00:05 МСК сквозные тесты и снимки не запускай.
- **Сквозные тесты зависят от порядка файлов:** доказательство для своего файла — прогон одного файла сразу после `npm run db:seed`, затем полный прогон.
- **Машина нестабильна** — [R-node-crashes](../research/R-node-crashes.md). Команды `npm`, `npx`, `node` — только с привязкой к ядрам, из Git Bash: `(cd app && cmd //c "start /b /wait /affinity FFFF0000 npm test")`. `cmd start` не передаёт код возврата: итог — по строкам `passed` и `failed`. Падение с кодом `3221225477` или `3221225622`, `ECONNRESET`, «Page crashed» без проваленных проверок — повтори один раз и назови оба результата.
- **Общую проверку `tools/check_all.py` не запускай:** её прогонит оркестратор. У неё нет справки: любой параметр запускает прогон.
- **Команду с `cd` бери в скобки.** Файлы правь только инструментом записи или правки: `mv`, `cp`, `sed -i` для файлов репозитория нельзя. Heredoc нельзя — ни для файлов, ни для `python`, ни для `node`: свой скрипт запиши файлом в `%LOCALAPPDATA%\dekanat-runs\` и запусти оттуда. Каталог `dekanat-runs` целиком не перечисляй: там сотни файлов.
- **После правки тестов — `npm run typecheck` до сквозного прогона:** `next build` проверяет и тесты — ошибка ИИ 134.
- **Локальная база** — `127.0.0.1:5432`. Перед прогоном: полный путь `%LOCALAPPDATA%\dekanat-pg\pgsql\bin\pg_isready -h 127.0.0.1 -p 5432`, смотри код возврата. Не отвечает — не чини, верни в отчёте. Красные все тесты подряд — проверь право чтения скриптом `%LOCALAPPDATA%\dekanat-runs\3.7-check-privilege.mjs` с переменной `REPO_DIR`; возвращает право `npm run db:migrate`. Файл `.env` не читай.
- **Перед отчётом проверь, что твоих процессов не осталось:** `node`, `next`, `playwright`, `chromium` с папкой проекта в командной строке. Останови только свои; базу и чужие процессы `node` и `chrome` не трогай.
