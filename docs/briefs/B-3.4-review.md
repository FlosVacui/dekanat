## Ловушки

Запуск — отдельным процессом через `Start-Process` в PowerShell: `pg_ctl -D <папка данных> -l <файл журнала> -o "-p 5432 -c listen_addresses=127.0.0.1" start`. Без базы проверка пропускает два шага продукта, а код возврата нулевой: читай итог.
