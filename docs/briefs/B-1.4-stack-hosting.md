## Что сделать
Сегодня 10.11.2026. Ответь на вопросы по открытым источникам.

1. **Хостинг.** Три–пять российских провайдеров VPS с тарифом, которого хватит для Next.js и PostgreSQL в Docker Compose (ориентир: 1–2 ядра, 2 ГБ памяти). По каждому: цена в месяц, оплата — помесячно или по часам, принимает ли российскую карту, где датацентр, сколько времени до готового сервера. Отдельно: один вариант «большое облако» (например, Yandex Cloud) и один-два российских сервиса «выложил и работает».
2. **Домен.** Цена регистрации `.ru` у двух–трёх регистраторов; что нужно для регистрации частному лицу; сколько времени до работающего домена. Запасной путь без покупки домена: что дают провайдеры и как с ним работает HTTPS.
3. **HTTPS.** Выпускает ли Let's Encrypt сертификаты для серверов в России на 10.11.2026; если есть ограничения — какие и чем заменить.
4. **Доступ из России без VPN.** Какие зарубежные площадки (например, Vercel, Netlify, Supabase, Cloudflare, Render, Fly.io) имеют подтверждённые проблемы с доступом или оплатой из России. Только с источником и датой; без источника — «предположение».
5. **Стек.** Сравни три варианта из Р-3: Next.js и TypeScript с PostgreSQL; FastAPI с шаблонами; готовый сервис данных. По каждому: вход по логину и паролю и хеш пароля (какие библиотеки), работа с базой, тесты в браузере на экране 360 px, как вариант растёт вместе с числом пользователей (ТР-2), насколько хорошо с ним работают ИИ-ассистенты. Текущие стабильные версии и лицензии — со страниц проектов, со ссылкой.
6. **Установка зависимостей с российского сервера.** Доступны ли реестр npm, Docker Hub и реестр контейнеров GitHub с серверов в России; какие есть зеркала.
7. **API моделей (для Р-5).** Какие API языковых моделей работают с российского сервера без VPN и оплачиваются российской картой. По каждому: цена, бесплатный лимит, как получить ключ и сколько это занимает.
