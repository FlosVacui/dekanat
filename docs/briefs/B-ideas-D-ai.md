## Провайдер
Один серверный клиент OpenAI-совместимого API (`/v1/chat/completions`) — так работают Yandex AI Studio и Cloud.ru (R-1.4, L3–L4; Anthropic и OpenAI из России недоступны, L5–L6). Файл `app/src/server/ai.ts` (`import 'server-only'`). Переменные — только через `app/src/server/config.ts`: `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL`, необязательная `AI_FOLDER_ID` (для Яндекса — заголовок `OpenAI-Project`). Нет `AI_API_KEY` — `aiEnabled() === false`, функции идут по запасному пути. Таймаут 8 с, одна попытка, ошибка → запасной путь и строка в `security-log`/обычный лог без текста запроса студента. Ключ в браузер не попадает. Имена переменных — в `.env.example`, если файл есть; `.env` не читать.

## 1. Разбор фразы моделью (идея №1)
В `app/src/lib/intent.ts` уже есть разбор по ключевым словам (сделан исполнителем B). Добавь серверную обёртку `parseRequestIntent(text)`: при `aiEnabled()` — запрос к модели с системным промптом «верни JSON {kind, purpose, dueDate, copies}», `kind` строго из `REQUEST_KINDS`, дата — ISO; ответ валидируется теми же проверками, что форма (`isRequestKind` и т. п.). Невалидно или ошибка → разбор по ключевым словам. Подпись у поля честная: «Разобрано ИИ — проверьте поля» или «Подбор по ключевым словам». Фраза студента ограничена 300 символами; персональные данные в промпт не добавляются — только текст фразы и список типов.
Промпт модели сохрани дословно в `prompts/` как `P-AI-01-intent.md` (это промпт продукта, жюри его увидит).

## 2. Черновик ответа сотруднику на вопрос (идея №37)
На странице вопроса у сотрудника `/staff/questions/[id]` — кнопка «Черновик ИИ». Сервер берёт текст вопроса (без ФИО и личных данных), просит модель короткий вежливый ответ от деканата, не больше 600 символов, без выдуманных сроков и пунктов положений: где нужен конкретный пункт — «[уточнить пункт положения]». Черновик вставляется в поле ответа; сотрудник правит и отправляет сам. Автоотправки нет. Без ключа кнопка не показывается. Пометка у черновика: «Черновик подготовлен ИИ. Проверьте перед отправкой». Промпт — дословно в `prompts/P-AI-02-staff-draft.md`.
