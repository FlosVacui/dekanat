# Матрица требований

Каждое требование задания и каждый критерий имеют номер, этап, где они закрываются, и способ проверки. Колонка «Доказательство» заполняется при приёмке пакета: ссылка на тест, снимок экрана, отчёт или коммит. Пустая клетка на воротах 5 — блокирующее замечание.

Источник требований — [research/task-original.md](research/task-original.md). Критерии: **К1** — проработанность идеи, **К2** — масштаб использования нейротехнологий, **К3** — имплементация, **К4** — качество.
