# Перечень инструментов

Все ИИ-инструменты, среды и сервисы проекта и для чего использован каждый. Файл пополняет каждая смена: новый инструмент записывается в день первого применения. Он идёт в описание процесса (требование СД-3.2).

Записывается только то, чем действительно пользовались. Планы сюда не попадают.

## ИИ-инструменты
| Инструмент | Для чего использован | С какой смены |
|---|---|---|
| Claude Code в приложении Claude, вкладка Code; модель Claude Fable 5.2 | Оркестратор: уточняющие вопросы, план, документы процесса, перенос и правка инструментов, учёт, роли субагентов и команды | 10.11, смена 1 |
| Встроенный браузер приложения Claude | Чтение страницы номинации, кабинета конкурса и Регламента под входом участника | 10.11, смена 1 |
| Загрузка страниц документации Claude Code | Сверка синтаксиса ролей, команд и настроек | 10.11, смена 1 |
| Инструмент `get_usage` приложения Claude | Снимки лимитов и контекста в начале смены и после крупных шагов. В смене 1 лимиты тоже снимались; чем именно — в журнале не записано | 10.11, смена 2 |
| Субагент Claude Code с ролью `prompt-reviewer`; модель Claude Sonnet 5.5, effort high | Независимое ревью правил сессии, ролей и команд со свежим контекстом: [задание](../briefs/B-0.3-prompt-review.md) | 10.11, смена 2 |
| Субагенты Claude Code с ролью `researcher`; модель Claude Sonnet 5.5, effort high; поиск и чтение открытых страниц | Ресерч этапа 1 по заданиям: [1.4](../briefs/B-1.4-stack-hosting.md), [1.2](../briefs/B-1.2-cabinets.md) | 10.11, смена 3 |
| Диалог с вариантами ответа в приложении Claude | Оркестратор задаёт пользователю вопросы с вариантами и рекомендацией; ответы записываются в журнал | 10.11, смена 3 |

Что изменено — [ROADMAP, раздел 9](../ROADMAP.md#9-что-взято-из-прошлого-проекта-команды-и-что-упрощено).
