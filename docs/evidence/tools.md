# Перечень инструментов

Все ИИ-инструменты, среды и сервисы проекта и для чего использован каждый. Файл пополняет каждая смена: новый инструмент записывается в день первого применения. Он идёт в описание процесса (требование СД-3.2).

Записывается только то, чем действительно пользовались. Планы сюда не попадают.

|---|---|---|
