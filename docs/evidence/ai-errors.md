# Журнал ошибок ИИ

Что ИИ сделал не так, как это заметили и как исправили. Запись делается в момент находки. Этот файл идёт в описание процесса: задание просит показать работу с ошибками ИИ.

Правила:
- Записываются только настоящие ошибки. Ошибок «для галочки» здесь нет.
- Запись не удаляется и не смягчается, когда ошибка исправлена.
- Ошибки, которые нашло ревью, лежат ещё и в отчётах `docs/reviews/`.

Смены обозначены датой и номером: «10.11, смена 1» — первая сессия проекта.
