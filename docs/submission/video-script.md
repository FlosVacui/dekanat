## Правила
- **Показываем только то, что есть в прототипе.** Пуш-уведомлений на телефон нет — есть колокольчик в кабинете. ИИ-помощника нет — его не упоминаем.
- **Данные вымышленные.** В кадре пометка «Концепт…» из подвала хотя бы один раз.
- **В кадре нет ничего личного.** На телефоне режим «Не беспокоить», чтобы не всплыли чужие уведомления. Нет чужих вкладок, закладок, почты, лиц посторонних.
- **Числа за кадром — только из репозитория:** из сводки анкеты и из README на день записи.

## Как снимать
1. **Запись экрана телефона** — встроенная запись: на iPhone — «Пункт управления», «Запись экрана»; на Android — «Запись экрана» в шторке. Браузер — обычный, адрес https://moy-dekanat.ru.
2. **«Телефон в руке»** — два-три коротких плана со второго телефона: рука листает «Сегодня». Задание просит показать работу с телефона: этот план — прямое доказательство.
3. **Сотрудник** — запись экрана компьютера на 1280 px, тот же адрес.
4. **Голос** — отдельно, в тихой комнате, на телефон или микрофон, по тексту ниже. Читать спокойно: примерно 130 слов в минуту.
5. **Монтаж** — любой видеоредактор. Какой взяли — строка в `docs/evidence/tools.md` в день монтажа.
6. **Аккаунт и время.** Шаг 7 заказывает справку: ночное освежение заявки посетителей не удаляет, они останутся в аккаунте, который увидит жюри. Аккаунт для записи — тот же вопрос участнику А, что для пробы: `docs/research/trial/README.md`, «Перед пробой» — в PR №36, в `main` его пока нет. Не записывать с 23:50 до 00:10 и с 03:50 до 04:10: в 00:07 и 04:07 сервер освежает данные.

## Перед записью — проверить
- [ ] Ответ участника А: аккаунт для записи и чистка заявок после неё.
- [ ] Шаг 1: фраза про однокурсников сверена со [сводкой анкеты](../research/survey/summary.md) на день записи. Если ночные ответы окажутся пробными, она остаётся верной: «легко» и «очень легко» не выбрал никто.
- [ ] Шаг 6: «сдано два из семи», «пересдача двадцать первого ноября» — сверены с экраном на день записи: даты набора зависят от дня заполнения.
- [ ] Шаг 10: отказ по чужому адресу проверен заранее, без записи.
- [ ] Шаг 11: число смен или ошибок за кадром — если нужно — из README на день записи.
- [ ] Режим «Не беспокоить» включён.
