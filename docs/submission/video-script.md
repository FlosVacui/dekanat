## Правила
- **Показываем только то, что есть в прототипе** на https://moy-dekanat.ru в день записи.
- **Данные вымышленные.** Пометка «Концепт» в кадре хотя бы один раз — экран входа.
- **В кадре нет ничего личного.** Компьютер — гостевое окно Chrome на весь экран, F11. Телефон — режим «Не беспокоить».
- **Числа в голосе — только из репозитория или с экрана в день записи.** Числа успеваемости голос не называет: они зависят от дня заполнения набора.
- **Пароли вводит человек.** На экране они скрыты точками.

## Как снимать
1. **Компьютер.** Гостевое окно Chrome на мониторе 1920×1080, масштаб 100 %, F11. Запись экрана запускает оркестратор (`ffmpeg`, `gdigrab`). Участник идёт по сценам 1–11 по порядку. Между сценами — пауза 2–3 секунды без движения мыши.
2. **Телефон.** Встроенная запись экрана, обычный браузер, тот же адрес. Сцены 1–11 по порядку, тоже с паузами. Снимать после компьютера: в сцене 9 статус «Готова» ставит сотрудник на компьютере, телефон показывает уже готовую заявку.
3. **Не записывать** с 23:50 до 00:10 и с 03:50 до 04:10: в 00:07 и 04:07 сервер освежает данные.
4. **Заявки из сцен 5–6** останутся в аккаунте студента 1: ночное освежение заявки посетителей не удаляет. Участник А это принял, 22.11.
