## Тесты с пометкой «ожидаемо падает»

Три теста. Каждый краснеет, когда дыру закроют: тогда пометку снимают.

Причина падения проверена отдельно, одноразовым тестом без пометки (удалён): самодельный объект получил профиль Б с ФИО Б, а «студент-сотрудник» — список заявок набора. То есть тесты падают из-за дыры, а не из-за сломанного стенда.

## Итог
Доработать — одно существенное замечание. Базовый набор держится: чужая заявка не открывается ни по адресу, ни через серверное действие; владелец и статус берутся с сервера; без входа данных нет; пароль лежит хешем scrypt; ключей в файлах браузера нет. Замечаний четыре: существенное R-2.6-1 — в ответах нет заголовков защиты, хотя ADR-0004 их требует; незначительное R-2.6-2 — проверку действующего лица можно обойти подделкой прототипа; два предложения.
