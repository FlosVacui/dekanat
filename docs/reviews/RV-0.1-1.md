  ок        Права на запуск и BOM скриптов (0 с)

Код возврата 0, восемь шагов из восьми.

**Якоря.** `check_links.py` сам сверяет `#якорь` с заголовками (`tools/check_links.py`, функции `anchors` и `slug`), так что «не видит якорей» к нему не относится. Я повторил проверку своим скриптом с отдельной функцией `slug`: в 11 проверяемых файлах и шести шаблонах 158 относительных ссылок, из них нет файла — 0, нет заголовка с таким якорем — 0. Пути в обратных кавычках (`docs/...`, `tools/...`, `.claude/...`) существуют; не нашлись только заготовки-образцы (`H-NNN.md`, `docs/1.4-stack`, `app/.env.local`, `.claude/settings.local.json`, `График_работ.xlsx`), и они такими и задуманы.

**Чего проверка ссылок не видит** (и что нашла я): ссылки внутри обратных кавычек и блоков кода она пропускает; текстовые отсылки «раздел 8», «шаг 7» не проверяет; смысл в целевом разделе не сверяет. Текстовые отсылки на выбор проверены вручную: `ROADMAP` разделы 6–9, `R-1.4` раздел 3.1 и 3.3, `S-2.1` раздел 4, `SUMMARY` разделы 2, 4, 5, 6 — совпадают с содержимым.

## Матрица требований: строки, которые должен был закрыть этап 0

Этап 0 не закрывает ни одного требования задания сам: он создаёт среду, а доказательства дают пакеты следующих этапов. Строк, у которых пустая клетка «Доказательство» была бы замечанием по этапу 0, нет.

Замечанием это не считаю: закрываются они пакетом 5.1 (см. R-0.1-19).
