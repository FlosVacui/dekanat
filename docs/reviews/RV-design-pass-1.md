## Что проверено и в порядке
Безопасность, пункт 1 задания:
- «Ждёт вас»: вся выборка идёт через `listMyGrades`, `listMyRequests`, `listMyQuestions`, `getMyProfile` с `actor` из `requireStudentActor()`. Идентификаторов из адреса нет. Сборка `buildWaiting` — чистая функция.
- `/verify/[code]`: код проверяется `verifyCertificateCode` (HMAC-SHA-256, подпись 128 бит, `timingSafeEqual`, длина кода ограничена 100, формат base64url). Без секрета — 404. Неверный, изменённый и неизвестный код дают один и тот же ответ «Справка не найдена» с кодом 404. Слой доступа вызывается только с номером из подписанного кода. Выдаются только документ, «Иванов И. И.», курс, группа, дата. Номера заявки, адреса и примечания нет. Пометка «Прототип. Данные вымышленные» есть, `robots: noindex` есть.
- Печатная справка `/requests/[id]/certificate`: `getMyRequest(actor, id)` ищет вместе с владельцем, чужая и несуществующая заявка — `denyRecord` → 404 с записью в журнал; сотрудник получает 403. Страница требует `dean_certificate`, `on_demand`, статус «готова» или «выдана». Хост для QR проверяется регулярным выражением; влияет только на собственный ответ запроса.
- `createMyReadyCertificate`: владелец из `Actor` (`requireStudent`), advisory-lock и лимит на пару «аккаунт + адрес» и на аккаунт за сутки (общий с обычной подачей), одна транзакция с двумя событиями истории, `RequestLimitError` обрабатывается действием, `ip` нормализуется. Тесты: `dal-certificate.test.ts` (в том числе отказ сотруднику и чужой код).
- ИИ, `server/ai.ts`: `import 'server-only'`; ни один клиентский компонент не импортирует `@/server/*` (проверено поиском); `NEXT_PUBLIC_` в `src` нет; ключ идёт только в заголовок `Authorization` с сервера; адрес — только `https` (или localhost); `redirect: 'error'`; таймаут 8 с через `AbortController`, одна попытка; на любую ошибку причина — слово без текста запроса и ответа; без ключа `aiEnabled() === false`, `fetch` не вызывается (тест). В модель уходят только фраза до 300 знаков (или текст вопроса), список видов и назначений, сегодняшний день. ФИО, группы, номера нет. Ответ модели проверяется `validateModelIntent` (вид, назначение, дата не раньше сегодня и не позже года, 1–10 экземпляров); черновик очищается и обрезается до 600 знаков. Промпты в `prompts/P-AI-01`, `P-AI-02` сверяются с кодом тестом; подпись у поля: «Разобрано ИИ — проверьте поля» и «Подбор по ключевым словам». Предел вызовов есть (см. R-design-pass-11).
- Черновик ответа: `draftAnswerAction` требует сотрудника, вопрос ищется `getCohortQuestion` вместе с набором из сессии (чужой — отказ и запись в журнал), на вопрос с ответом черновик не строится, ничего не сохраняется и не отправляется; без ключа кнопки нет; пометка «Черновик подготовлен ИИ. Проверьте перед отправкой» есть.
