# Подготовка рабочего места

Для участника, который впервые открывает репозиторий. После этих шагов свежая сессия Claude Code начинает работу по [CLAUDE.md](../CLAUDE.md) — без чата, где всё готовилось.

Как устроена работа — [PROCESS.md](PROCESS.md). Ветки и коммиты — [CONTRIBUTING.md](../CONTRIBUTING.md).

## 1. Программы и адрес для коммитов
Нужно до запуска скрипта подготовки:

| Программа | Зачем | Windows | macOS и Linux |
|---|---|---|---|
| git | История и обмен | `winget install --id Git.Git -e` | из пакетного менеджера |
| GitHub CLI `gh` | Вход в GitHub, PR | `winget install --id GitHub.cli -e` | из пакетного менеджера |
| uv | Запуск инструментов из `tools/`; системный Python не нужен | `winget install --id astral-sh.uv -e` | по инструкции на сайте uv |
| Claude Code | Сессии разработки: приложение Claude, вкладка Code, или терминал | Со своей подпиской | Со своей подпиской |
| Node.js LTS | Продукт — нужен с этапа 2 | `winget install --id OpenJS.NodeJS.LTS -e` | из пакетного менеджера |

gitleaks и pre-commit ставит сам скрипт подготовки.

**Адрес для коммитов — служебный адрес GitHub.** Репозиторий станет публичным, личная почта не должна попасть в историю.
1. GitHub → Settings → Emails → включить «Keep my email addresses private».
2. Там же скопировать адрес вида `<число>+<логин>@users.noreply.github.com`.
3. В папке репозитория:
   ```
   git config user.name "<логин GitHub>"
   git config user.email "<число>+<логин>@users.noreply.github.com"
   ```

Настройка локальная: она действует только в этом репозитории.

## 2. Входы
| Куда | Как получить | Нужно с |
|---|---|---|
| GitHub | `gh auth login` своим аккаунтом | сразу |
| Репозиторий проекта | Приглашение от участника А. Репозиторий приватный до решения [Р-8](DECISIONS.md#р-8-доступ-жюри-к-репозиторию) | после пакета 0.4 |
| Claude | Свой профиль с тарифом Pro | сразу |
| Кабинет конкурса | Свой вход. Каждый сам загружает согласие, скан студенческого и отмечает Регламент — срок 16.11 | сразу |
| Хостинг и домен | У участника А; доступ — по необходимости | этап 2 |

Чужие входы не передаются. Пароли и ключи не пишутся в чат команды и в репозиторий.

## 3. Клон и скрипт подготовки
Папку не кладём туда, где работает облачная синхронизация (OneDrive, iCloud): она ломает `.git`.

```
gh repo clone <владелец>/<репозиторий>
cd <репозиторий>
```

Windows:
```
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\bootstrap.ps1
```

macOS и Linux:
```
./tools/bootstrap.sh
```

Скрипт проверяет программы и вход в GitHub, проверяет адрес коммитов, ставит gitleaks и pre-commit, создаёт `.env` из образца и читает учёт. Его можно запускать повторно. После него терминал нужно открыть заново.

Проверка, что всё работает:
```
uv run tools/check_all.py
```

Пока репозитория на GitHub нет, папку передаёт участник А.

## 4. Работа сменой
Одна смена — один разработчик, от `/start` до `/handoff`.

1. Получить от предыдущего разработчика промпт `H-NNN`. Его копия лежит в `prompts/handoff/`.
2. Открыть Claude Code в корне репозитория.
3. Набрать `/start` или вставить промпт. Сессия сама сделает `git pull`, покажет сроки, прочитает [HANDOFF.md](HANDOFF.md) и снимет лимиты.
4. Работать в своей зоне и в своей ветке — [PROCESS, «Люди и зоны»](PROCESS.md#люди-и-зоны).
5. Человек проверяет поведение: открыть, пройти сценарий, посмотреть с телефона. Код проверяют субагенты.
6. В конце — `/handoff`: коммит, журнал, учёт, новый `HANDOFF.md` и промпт для следующего.
7. Переслать промпт следующему разработчику.

Что записать руками, пока идёт смена:
- снимок экрана чата с ИИ — один-два на этап, в `docs/evidence/screenshots/`;
- всё, что сделано вручную, — сказать сессии, она внесёт в [evidence/manual.md](evidence/manual.md);
- ответ внешней нейросети — как есть, в файл запроса в `docs/external/`.

На снимках экрана не должно быть личных путей, почты, имён и чужих проектов.

## 5. Чего нет в git и как это получить
| Что | Почему не в git | Как получить |
|---|---|---|
| `.env` | Секреты | Скрипт создаёт его из `.env.example`. Значения передаёт владелец зоны А лично, не через чат команды. На этапе 0 переменных ещё нет |
| Ключ API модели | Секрет; появится, только если выбран ИИ-помощник ([Р-5](DECISIONS.md#р-5-ии-помощник-в-кабинете)) | У участника А; живёт только на сервере и в `.env` |
| Доступ к хостингу и домену | Личные учётные записи | У участника А; появится на этапе 2 |
| `docs/tracker/График_работ.xlsx` | Двоичный файл втроём не сливается | `uv run tools/tracker.py build` |
| `.claude/settings.local.json` | Личные настройки Claude Code | Создаётся у каждого сам; общие настройки — `.claude/settings.json` |
| Исходники и рендеры видео | Тяжёлые файлы | На диске участника, который монтирует; итог — по ссылке ([Р-7](DECISIONS.md#р-7-где-видео)) |
| Документы участников для конкурса | Персональные данные | Каждый загружает сам в свой профиль конкурса |

Настройки Claude вне репозитория:
- Глобальные скиллы и коннекторы проекту не нужны. Роли и команды лежат в `.claude/` и приходят с клоном.
- Страницы конкурса читаются встроенным браузером приложения Claude под входом участника.
- Файл `CLAUDE.md` в папке выше репозитория добавляет свои правила в сессии проекта. Скрипт подготовки о нём предупреждает.
- `.claude/settings.json` запрещает сессии читать `.env` и семь его вариантов, названных поимённо: `.env.local`, `.env.development`, `.env.production`, `.env.test` и те же три с окончанием `.local`. Образец `.env.example` читать можно: секретов в нём нет. Появился файл с секретами под другим именем — его добавляют в список.

## 6. Если что-то не работает
| Что видно | Что делать |
|---|---|
| Скрипт не находит `gitleaks` или `pre-commit` после установки | Закрыть терминал и открыть новый |
| Коммит отклонён хуком | Прочитать сообщение: gitleaks нашёл секрет или `check_clean.py` — личный путь или почту. Убрать и повторить |
| `tracker.py` пишет «файл занят» | Закрыть Excel и запустить `uv run tools/tracker.py build` |
| `check_all.py` пропустил шаг | На этой машине нет нужной программы (bash, PowerShell 5.1, gitleaks). Шаг пройдёт в CI |
| Сессия не знает, что делать | Спросить «что делать дальше?» — она отвечает по `CLAUDE.md` и `HANDOFF.md` |
