## Как запускать скрипты на сервере
Команду запускает пользователь в своём PowerShell. Образец — подставить полный путь к файлу скрипта на ноутбуке:

`ssh dekanat "echo $([Convert]::ToBase64String([IO.File]::ReadAllBytes('<полный путь>\deploy\server\NN-имя.sh'))) | base64 -d | bash"`

Аргументы — в конце: `| base64 -d | bash -s -- <аргументы>`. Пароль ключа спрашивается один раз. Вывод скриптов — латиницей, без адреса и без значений окружения.

Обновление сервера — одна команда: `06-update.sh` с аргументом `main`. Он сам берёт ветку; `02-repo.sh` для этого не нужен.
