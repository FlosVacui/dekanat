## Что сломано или под сомнением
- **Тест `login-limits.test.ts`, строка 241, краснеет примерно раз из четырёх** — по словам ревьюера; причина — R-3.1-1. У оркестратора оба прогона общей проверки после исполнителя были зелёными. Красный шаг «модульные тесты» до правок — скорее это, чем новая поломка.
- **Шесть тестов зависят от того, что шаги уложатся в секунду** — R-3.1-2: на медленной машине возможны редкие падения. В правках.
- **Права роли приложения на три таблицы счётчиков выданы в миграции с именем роли `dekanat_app` в тексте** — R-3.1-5. Роль названа иначе — права молча не выдаются, вход падает с отказом базы. В правках.
- **Поправку ADR-0003 аудит не видел.** Ревьюер 3.1 с обоими решениями согласился и нашёл в ней один пробел — R-3.1-4, поправка дополнена.
- **Действие входа принимает запрос без заголовка Origin.** Защищают кука `SameSite=Lax` и проверка Next.js для чужого Origin. Своя проверка не пишется — решение по R-3.1-11; остальные действия без Origin не проверены: IMP-018.
- **Экран входа экранным чтецом никто не слушал.** Не проверено и время ответа для логина с неопубликованным паролем, и поведение при нехватке памяти на счёт хеша.
- **`app/tests/unit/helpers.ts` подменяет адрес** в двух функциях слоя для вызовов с адресом `'test'` или без адреса: иначе файл аудитора упирается в лимит записи. Ревьюер: атакующие тесты это не ослабляет. Убрать — IMP-018, пункт 4.
- **Числа лимита не сходятся с концом смены 9:** там 64 / 34 / 52 % и сброс недельного 18.11; смена 10 началась через несколько минут с 3 / 25 / 40 % и сбросом 15.11. Похоже на другой профиль; пользователь не ответил.
- Прежние, без изменений: политика содержимого со `'unsafe-inline'` — [IMP-017](ISSUES.md); файлы Compose никто не запускал — IMP-016; сквозной тест, снимки и атакующие тесты стирают заявки основного набора — на сервере не запускать; локальная база после перезагрузки ноутбука запускается заново — [B-2.4-e2e](briefs/B-2.4-e2e.md), «Ловушки»; 13 уязвимостей средней серьёзности в зависимостях — проверки Д-01 и Д-02 на воротах 3; решения ворот 1 приняты без голоса студентов; лицензии инструментов разработки не сверены — [IMP-007](ISSUES.md).
