## Как запускать скрипты на сервере
Команду запускает пользователь в своём PowerShell. Образец — подставить полный путь к файлу скрипта на ноутбуке:

`ssh dekanat "echo $([Convert]::ToBase64String([IO.File]::ReadAllBytes('<полный путь>\deploy\server\NN-имя.sh'))) | base64 -d | bash"`

Аргументы — в конце: `| base64 -d | bash -s -- <аргументы>`. Пароль ключа спрашивается один раз. Вывод скриптов — латиницей, без адреса и без значений окружения.

Обновление сервера — одна команда: `06-update.sh` с аргументом `main`. Он сам берёт ветку; `02-repo.sh` для этого не нужен.

Освежение данных — `07-refresh.sh`, только без аргумента.

## Как запускать общую проверку
Из Git Bash, в фоне, вывод — в файл вне репозитория, с привязкой к логическим процессорам 16–31:

`cmd //c "start /b /wait /affinity FFFF0000 uv run tools/check_all.py"`

Перед запуском — `pg_isready` с кодом возврата 0 и поиск оставшихся процессов субагента и своих фоновых скриптов по командной строке. В итоге нужно 12 шагов «ок». Команды `npm` в папке `app/` запускаются так же: `(cd app && cmd //c "start /b /wait /affinity FFFF0000 npm test")`. С 23:50 до 00:05 МСК не запускать. `cmd start` не передаёт код возврата: итог читать по строкам «ок», `passed` и `failed`. Полный сквозной прогон — около 195 тестов, около пяти минут.
