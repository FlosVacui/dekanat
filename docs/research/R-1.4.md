# R-1.4. Стек, хостинг с доступом из России, API моделей

Дата работы: 10.11.2026. Все «дата обращения» ниже — 10.11.2026. Исполнитель: researcher (Sonnet 5.5 / high). Задание: [B-1.4](../briefs/B-1.4-stack-hosting.md).

Как читать надёжность источника:
- **высокая** — страница самого сервиса, официальная документация, реестр пакетов;
- **средняя** — крупное издание или статья с измерениями и ссылками;
- **низкая** — блог, форум, пост в соцсети, сводка поиска без первоисточника, реклама посредника.

Как читались страницы: через инструмент, который пересказывает страницу. Страницы, которые строятся скриптом (REG.RU, Timeweb, Selectel-калькулятор, Yandex-прайс), он часто не показывает. Где цену не удалось увидеть на странице сервиса, это написано.

## 1. Вопросы и короткие ответы

1. **Хостинг.** Дешёвый российский VPS с 2 ядрами и 2 ГБ есть и принимает российские карты. Подтверждено на странице сервиса: Hostkey, 560 ₽ в месяц (2 vCPU, 2 ГБ, 60 ГБ SSD). У Selectel такой тариф стоит 400 ₽ в месяц, но на 10.11 страница пишет «VDS временно недоступны, всё распродано». У Timeweb Cloud на странице видна только линейка Ultra: 1 ядро и 2 ГБ — 3 000 ₽ в месяц. Это выше бюджета. Дешёвые линии Timeweb на странице не показаны. У Beget заказ VPS закрыт после кибератаки 1–2 ноября. «Большое облако»: Yandex Cloud, оплата по часам, стартовый грант 4 000 ₽ на 60 дней. «Выложил и работает»: Amvera (от 170 ₽ в месяц) и Timeweb App Platform (цена на странице не названа).
2. **Домен.** Регистрация `.ru`: 120 ₽ (Selectel), 200 ₽ (Timeweb). Продление 399–450 ₽. **Новое с 1.09.2026:** для регистрации и продления `.ru` нужна идентификация через Госуслуги. Для физлица — подтверждённая учётная запись. Без неё домен не купить. Запасной путь без домена есть: Timeweb App Platform даёт бесплатный технический домен с сертификатом Let's Encrypt.
3. **HTTPS.** Let's Encrypt для частных лиц и негосударственных компаний из России выдаёт сертификаты. Источники — июнь–сентябрь 2026. Госучреждения и лица из санкционных списков отказ получают. Политика пишет «может», не «обязан». Я не мог выпустить сертификат, поэтому проверка выпуска — на первом сервере. Запасные пути: DNS-проверка, сертификат хостера, сертификат по IP-адресу от Let's Encrypt (160 часов).
4. **Доступ без VPN.** Подтверждённой блокировки с первоисточником не найдено ни для одной из шести зарубежных площадок. Есть косвенные данные. Vercel и Netlify: посты пользователей о блокировке (низкая надёжность). Оплата: Stripe не работает в России (страница Stripe), а Vercel, Netlify, Supabase, Render, Fly.io берут деньги через зарубежные платёжные системы — предположение. **Главное:** 10.11.2026 вышли замеры на Хабре — Россия «замораживает» трафик к целым сетям зарубежных хостеров (Hetzner, OVH, DigitalOcean и др.). Сервер надо брать в российской сети.
5. **Стек.** Вариант 1 (Next.js + TypeScript + PostgreSQL) подходит по всем пунктам. Вариант 2 (FastAPI + шаблоны) тоже подходит, но для мобильного интерфейса потребует больше ручной работы (предположение). Вариант 3 (готовый сервис): Supabase в облаке без VPN из России не подтверждён, а на своём сервере он превращается в вариант с Docker; PocketBase не дошёл до версии 1.0.
6. **Зависимости с российского сервера.** Docker Hub отвечал из Москвы 14.10.2026 (источник — блог VPN-сервиса). npm и GHCR: прямых данных не найдено. GitHub в 2026 году теряет 10–16 % соединений (сводка). PyPI не открывался 1.06.2026. Есть зеркала Docker Hub (Google, Timeweb, Яндекс), но их работу я не проверял. Надёжнее собирать образ вне сервера или проверить доступ на первом сервере.
7. **API моделей.** С российской карты и без VPN работают GigaChat (Сбер), YandexGPT / Alice AI (Яндекс), Cloud.ru. Anthropic, OpenAI и Google Gemini — Россия не в списке поддерживаемых стран. Бесплатный лимит: GigaChat — 365 млн токенов на 12 месяцев (страница от 07.10.2026). У Яндекса: грант 4 000 ₽ на 60 дней при привязке карты в момент создания платёжного аккаунта.

Под сомнением:
- **Заморозка трафика (F1)** — один автор, один город, два канала; достаточно для решения «брать российскую сеть», недостаточно, чтобы утверждать, что любая российская сеть пройдёт.
- **Let's Encrypt и `.ru` (T3)** — политика «может», не «обязан». Я сертификат не выпускал. Если выпуск сорвётся на сервере, нужны DNS-проверка или сертификат хостера. Проверить в первый день.
- **Разброс цен Timeweb (H4, H5)** — три разные цифры на 2 ГБ; нужна проверка в панели.
- **Размер бесплатного лимита GigaChat (L1)** — 365 млн токенов, страница обновлена 07.10.2026; прежние лимиты были заметно меньше. Проверить в кабинете.
- **PocketBase (S8)** — заметка в README о переносе и архивации репозитория; требует перепроверки.
- **Prisma (S5)** — `latest` в реестре указывает на 8.0.0-rc.33; нужна проверка перед выбором.
- **Достоверность пересказа.** Страницы читались через инструмент, который пересказывает текст. Числа из таблиц я переносил как есть, но мог пропустить сноски. Для цен, на которых будет принято решение об оплате, нужна проверка человеком на странице.
