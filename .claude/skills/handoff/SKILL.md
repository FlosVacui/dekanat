# /handoff — точка сохранения

Цель: следующий разработчик продолжает работу по одному репозиторию, без этого чата. Выполни шаги по порядку.

1. **Проверки.** `uv run tools/check_all.py`. Красный шаг исправь или опиши в `HANDOFF.md`, раздел «Что сломано или под сомнением». Красное не замалчивается.
2. **Материалы смены** — допиши, если ещё не записано:
   - новый итоговый промпт или задание — строка в `prompts/INDEX.md`;
   - ошибка ИИ — `docs/evidence/ai-errors.md`;
   - новый инструмент — `docs/evidence/tools.md`;
   - ручной шаг — `docs/evidence/manual.md`.
   Пишется только то, что было. Не было ошибок — так и пиши.
3. **Лимиты.** Сними `get_usage` или `/usage`.
4. **Журнал.** Новая запись сверху в `docs/history/JOURNAL.md` по шаблону `docs/templates/journal-entry.md`. Числа лимитов — из снимков начала и конца смены. Токены субагентов — из итогов их вызовов.
5. **Учёт.** `uv run tools/tracker.py mark <№> today "<статус>"` для каждого затронутого пакета. `uv run tools/tracker.py log --item <№> --what "…" --who "…" --tokens N`.
6. **HANDOFF.** Перепиши `docs/HANDOFF.md` целиком по шаблону `docs/templates/handoff.md`.
7. **Промпт для следующей сессии.** Новый файл `prompts/handoff/H-NNN.md`, номер — следующий по порядку. Промпт самодостаточный: кто ты, что прочитать, что сделать по порядку, чего не делать без подтверждения, чем закончить. Добавь строку в `prompts/INDEX.md`.
8. **Коммит.** Проверь `git status`: в коммит не попадают `.env`, личные файлы и постороннее. Сообщение — Conventional Commits по-русски. Учёт — отдельным коммитом `chore(tracker): …`. Удалённый репозиторий есть — push ветки. Создание репозитория, первый push и смена доступа — только после подтверждения разработчика.
9. **Ответ разработчику:** что сделано, что не закончено, какие вопросы ждут его, снимок лимитов и текст промпта целиком — под копирование.

В журнале и `HANDOFF.md` стоит хеш коммита с работой смены. Сами записи идут следующим коммитом: коммит не может содержать собственный хеш.

Подробно — `docs/PROCESS.md`, раздел «Смены».
